# Main

This file serves as a summary/directory of all information in the `/wiki` directory.

## Files

- `visuals.md`: Information about the site's appearance belongs here. This includes art, textures, layout, and related information. Anything gameplay related is not described in this file.

- `gameplay.md`: Key information about any gameplay exists in this file. Gameplay mechanics, concepts, and core details for the gameplay aspect of the website are specified. Additionally, gameplay visual information is detailed here.

- `gameplay_semantics_plan.md`: Design proposal for gesture judgement, note semantics, scoring, feedback, and implementation phases.

- `how_to_map.md`: Details on the mapping/charting steps and the relevant information regarding what the final map would look like.

- `imie - Answer Me (IOException).osu`: Sample `.osu` file for translating `.osu` to `.mimi`.

- `6W2N_chorus_timings.jsonc`: Official Magical Mirai/TextAlive staff chorus timing data for こたえて (ms char slots without text; phrase lines are in `//` comments). Songs opt in via the `lyric-chorus-timings` frontmatter field; the build copies `wiki/**` verbatim into the site output.
