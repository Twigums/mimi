TextAlive lyric dumper

Paste a song's TextAlive fields (copy them from src/tabs/songs/<song>.md frontmatter), load, and download a flat [{ text, start, end }] JSON of every lyric character and its timestamps. Use those start values with a lyric note's src=<ms> field to pin which character funnels in.

Open this through a local server (not file://), e.g. npx http-server src/tools, so the TextAlive API accepts the request.
